# sitios-clientes

Plantillas de sitios web estáticos para el servicio freelance de
creación de páginas para profesionales y pequeñas empresas.

## Demo de estilos

`index.html` + `styles/*.css`: una estructura de contenido única
(hero, perfil, servicios, trayectoria, blog, contacto) con 6
variantes visuales intercambiables via selector o `?style=<nombre>`:

| Estilo | Archivo | Perfil típico |
|---|---|---|
| Clásico sobrio | `clasico.css` | abogados, médicos, contadores |
| Moderno minimalista | `minimalista.css` | consultores, diseñadores |
| Cálido/cercano | `calido.css` | psicólogos, oficios |
| Bold/enérgico | `bold.css` | creativos, fotógrafos |
| Corporativo | `corporativo.css` | estudios, pymes |
| Dark | `dark.css` | técnicos, fotógrafos |
