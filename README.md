# sitios-clientes

Plantillas de sitios web estáticos para el servicio freelance de
creación de páginas para profesionales y pequeñas empresas.

## Demo de estilos

`index.html` + `styles/*.css`: una estructura de contenido única
(hero, perfil, servicios, trayectoria, blog, contacto) con 6
variantes visuales intercambiables via selector o `?style=<nombre>`:

| Estilo | Archivo | Inspirado en | Perfil típico |
|---|---|---|---|
| Clásico sobrio | `clasico.css` | Minimal Mistakes | abogados, médicos, contadores |
| Moderno minimalista | `minimalista.css` | AstroPaper / Read Only | consultores, diseñadores |
| Cálido/cercano | `calido.css` | Story (HTML5 UP) | psicólogos, oficios |
| Bold/enérgico | `bold.css` | Massively (HTML5 UP) | creativos, fotógrafos |
| Corporativo | `corporativo.css` | Spectral (HTML5 UP) | estudios, pymes |
| Dark | `dark.css` | Dimension (HTML5 UP) | técnicos, fotógrafos |

Las fotos del demo son placeholders de picsum.photos — en un sitio
real van las fotos del cliente. Animación de entrada orquestada +
micro-interacciones en hovers; `prefers-reduced-motion` respetado.
